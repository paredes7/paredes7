### 🚀 Sobre mí

- 💻 **Desarrollador Full Stack** con experiencia creando aplicaciones web y móviles funcionales, intuitivas y colaborativas.

- 🎨 Apasionado por escribir **código limpio**, estructurar arquitecturas escalables y brindar una excelente experiencia de usuario (UX/UI).

### 📌 Proyectos Destacados en Equipo

#### 🏢 1. Arasaka — Plataforma Web Empresarial Full Stack
> *Sistema web empresarial integral desarrollado de forma colaborativa, con arquitectura desacoplada para alta escalabilidad, gestión de servicios y autenticación de roles.*

- 🌐 **Frontend ([Arasaka_frontend](https://github.com/ArasakaSRL/Arasaka_frontend)):** Desarrollado con **React** y **TypeScript**, interfaz reactiva estilizada con **Tailwind CSS**, animaciones fluidas con **Framer Motion**, íconos con Lucide y navegación dinámica.
- ⚙️ **Backend ([Arasaka_backend](https://github.com/ArasakaSRL/Arasaka_backend)):** API RESTful desarrollada con **Laravel (PHP)**, implementando autenticación segura mediante **Laravel Sanctum**, gestión de almacenamiento multimedia con **Cloudinary** e integración en tiempo real con **Firebase**.
- 🧰 **Stack Tecnológico:** `React` • `TypeScript` • `Laravel` • `PHP` • `Firebase` • `Cloudinary` • `Tailwind CSS`
- 🔗 **Enlaces:** [Repositorio Frontend](https://github.com/ArasakaSRL/Arasaka_frontend) • [Repositorio Backend](https://github.com/ArasakaSRL/Arasaka_backend)

---

#### 🌿 2. Sanamente — Plataforma de Gestión y Bienestar Psicológico
> *Ecosistema digital colaborativo diseñado para optimizar la interacción, atención clínica, agendamiento de citas y seguimiento personalizado entre psicólogos y pacientes.*

- 📱 **Aplicación Móvil ([sanamente_apk](https://github.com/paredes7/sanamente_apk)):** Diseñada con **React Native** y **JavaScript**, enfocada en brindar una experiencia de usuario amigable, accesible y ágil para el registro y seguimiento diario de los pacientes.
- ⚙️ **Backend API ([Psicologos_Backend](https://github.com/Jhaseft/Psicologos_Backend)):** Arquitectura de microservicios y endpoints RESTful encargados de la persistencia de datos clínicos, administración de agendas y notificaciones de sesiones.
- 🧰 **Stack Tecnológico:** `React Native` • `JavaScript` • `RESTful APIs` • `Mobile UX/UI` • `PostgreSQL`
- 🔗 **Enlaces:** [Repositorio App Móvil](https://github.com/paredes7/sanamente_apk) • [Repositorio Backend API](https://github.com/Jhaseft/Psicologos_Backend)
